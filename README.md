# AI Resume Screener & Feedback

## 📌 Project Overview
AI Resume Screener & Feedback is an AI-powered tool designed to automatically analyze resumes, match them against job requirements, and provide constructive feedback to candidates. The project aims to simplify and speed up the resume screening process for recruiters while helping applicants improve their resumes.

## 🎯 Objectives
- Automate the initial screening of resumes.
- Match candidate resumes with job descriptions using AI/NLP techniques.
- Provide actionable feedback to candidates for resume improvement.
- Reduce manual effort and time spent in the hiring process.

## ⚙️ Installation Steps
1. Clone the repository:
```bash
   git clone https://github.com/Taqadus842/AI-Resume-Screener.git
```
2. Navigate to the project folder:
```bash
   cd AI-Resume-Screener
```
3. Create and activate a virtual environment:
```bash
   python -m venv venv
   venv\Scripts\activate   # Windows
```
4. Install dependencies:
```bash
   pip install -r requirements.txt
```
5. Run the application:
```bash
   python app.py
```
